# لِمَاذَا أَنْتَ..!!؟؟ — محرّك الفيلم
### قصيدة: راجح المحمدي | إخراج بصري: VOX Explainer + Kinetic Typography + Collage Art

هذا المجلد هو **محرّك إنتاج كامل** لا يحتاج After Effects. كل إطار يُرسم من معادلة زمنية،
ثم تُجمَّع الإطارات مع الملف الصوتي في فيديو واحد.

## ٢. الحقيقة الأولى: الصوت هو الساعة

المخطط التصوري الأصلي افترض مدة **١:٤٥**. الملف الصوتي الفعلي **١:٥٦ (116.208 ثانية)**.
لذلك **لم يُعتمد أي توقيت من المخطط** — أُعيد بناء التايم لاين كاملاً من قياس الإشارة:

```
القياس                          القيمة
─────────────────────────────────────────
المدة                            116.208 ثانية
الإيقاع (librosa beat track)     89.3 نبضة/دقيقة   (المخطط قال 88 — فرق ١٫٥٪)
بدايات النغمات المكتشفة          369
المقاطع الصوتية المرشّحة         26 (مدمجة)
عدد الكلمات المُثبّتة على الصوت   62 / 63
```

### بنية الأغنية كما قِيسَت فعلياً
| الفترة | المحتوى |
|---|---|
| 0:00 – 0:22 | مقدمة موسيقية (عود/قانون) — لا غناء |
| 0:22 – 0:31 | لماذا / لا أرى وطناً / ولا ظلاً / ولا شيئاً يسمى أنت |
| 0:31 – 0:39 | لماذا / كل هذا الحزنِ / في قلبي / يسمى أنت |
| 0:39 – 0:53 | أنت يا وطني / رديف الآهة الحرّى / رديف الغصة الكبرى / رديف مواجع الدنيا |
| 0:53 – 1:05 | أنت يا وطني / على الأيام مصلوب / على الطرقات مسفوك / على الأنقاض مشنوق |
| 1:05 – 1:29 | كلما أبكي / أرى وجعي / أرى جزعي / أرى دمعي الذي ينساب مني أنت |
| 1:29 – 1:53 | **تقسيمة آلات** — لا غناء (مؤكَّد باختبار أعمى) |
| 1:53 – 1:56 | لماذا أنت (القفلة) |

> **ملاحظة أمانة:** المقطع الثالث من القصيدة
> «لماذا / لا أرى الآهات والآلام / إلا أنت»
> **غير موجود في هذا التسجيل**. تعرّف الكلام لم يسمعه في أي تمريرة، والفحص الطيفي للمنطقة
> 88–113 ثانية يطابق بصمة المقدمة الموسيقية لا بصمة الصوت البشري
> (مركز طيفي 1392Hz وتسطّح 0.006 مقابل 1900Hz و0.013 للأجزاء المغنّاة).
> لم يُخترع نصّ لهذه المنطقة — عُولجت كمقطع موسيقي.

## ٣. كيف تُحدَّد توقيتات الكلمات

`scripts/build_timeline.py`:

1. تُجمَع كل الكلمات المكتشفة من أربع تمريرات Whisper (شاملة + مجزّأة + رأس + ذيل).
2. تُطبَّع عربياً على الجانبين: حذف التشكيل، توحيد `أ إ آ ٱ ← ا`، `ى ← ي`، `ة ← ه`.
3. محاذاة تسلسلية رتيبة **Needleman-Wunsch** بين نص القصيدة المرجعي والكلمات المكتشفة،
   بدرجة تشابه تعتمد `difflib` + مكافأة الاحتواء.
4. الكلمة التي سُمعَت ترث توقيتها الفعلي.
5. الكلمة التي لم تُسمَع تُستنتج بالاستيفاء المرجَّح بعدد المقاطع بين أقرب نقطتَي ارتكاز.
6. يُفرض حد أدنى 0.24 ثانية للكلمة، ثم الرتابة، ثم الحصر داخل حدود المشهد.

النتيجة: **62 من 63 كلمة** مُثبّتة على الصوت الحقيقي، والباقي مستنتج بين نقطتَي ارتكاز.

## ٤. الأصول البصرية

| النوع | المصدر |
|---|---|
| ٧ خلفيات | مولّدة بالذكاء الاصطناعي (أسلوب VOX، ألوان مطفية، ملمس ورقي) |
| خريطة اليمن | **حدود حقيقية** من GeoJSON، إسقاط مركاتور + تبسيط Douglas-Peucker (`scripts/make_geo.py`) |
| ١٣ دولة مجاورة | نفس المصدر — سياق الخريطة |
| الأيقونات والقلب والدمعة والأنقاض | مرسومة برمجياً كمسارات SVG في `templates/src/art.js` |
| خامة الورق والحبيبات | مبلَّطة مرة واحدة كصور ثابتة (`scripts/make_textures.py`) |
| الخطوط | Cairo / Tajawal / Amiri / IBM Plex Sans Arabic — محلية، بلا إنترنت |

> **لماذا الخامات مبلَّطة وليست فلاتر SVG؟** تحريك `feTurbulence` يُجبر المتصفح على إعادة
> حساب الفلتر في كل إطار من ٢٩٠٥ إطار. البلاطة الثابتة التي تتحرك تعطي نفس الأثر بأقل من ١٪ من التكلفة.

## ٥. ضبط السطوع — مشكلة حقيقية حُلّت رقمياً

|---|---|---|---|
| الصحراء | 227.4 | ×0.20 | ٢٢ |
| الأطلال (Isometric) | 144.9 | ×0.36 | ٢٤ |
| الكولاج | 49.7 | ×1.20 | ٢٤ |
| القلب | 42.9 | ×1.25 | ٢٢ |
| بورتريه الحطام | 35.2 | ×1.35 | ٢٦ |

النتيجة: متوسط إضاءة الفيلم كله بين **١٢ و٢٧** — متسق من أول إطار لآخر إطار.

## ٦. التشغيل

```bash
npm install
npx playwright install chromium
pip install numpy librosa faster-whisper

python3 scripts/analyze_audio.py  audio.mp3 beats       # الإيقاع ومنحنى الطاقة
python3 scripts/analyze_audio.py  audio.mp3 whisper     # توقيت الكلمات
python3 scripts/transcribe_chunks.py                    # تمريرة مجزّأة للتغطية الكاملة
python3 scripts/make_geo.py                             # الخرائط
python3 scripts/make_textures.py                        # الخامات
python3 scripts/build_timeline.py                       # ← التايم لاين
node   scripts/build_frame.js                           # تجميع القالب
node   scripts/qa.js                                    # فحص رقمي (تخطيط/خطوط/بكسل)
node   scripts/render_frames.js --workers=2             # ٢٩٠٥ إطار
node   scripts/compose_video.js                         # التجميع والمكساج
bash   scripts/push.sh "رسالة"                          # الرفع للمستودع
```

## ٧. أرقام الإنتاج

- **٢٩٠٥ إطار** بدقة 1920×1080
- **~0.295 ثانية/إطار** عبر عاملَين متوازيَين في Chromium
- لا توجد أي انتقالات جاهزة: كل انتقال إمّا تلاشٍ إلى الفحم (dip) أو تحوّل شكلي (morph)
- كل حركة **دالّة نقية للزمن** — إعادة رندر الإطار N تعطي نفس البكسلات دائماً،
  وهذا ما يجعل الرندر المتوازي والمجزّأ آمناً

## ٨. فحص الجودة بدون عين بشرية

`scripts/qa.js` يفحص ٤٥ نقطة زمنية ويتحقق من:
- الخطوط العربية محمّلة فعلاً (لا خط بديل، لا مربّعات)
- لا سطر يتجاوز المنطقة الآمنة 1920×1080
- لا `NaN` في أي تحويل (transform)
- إحصاء البكسل: متوسط الإضاءة، نسبة الأسود، نسبة الأحمر `#8B1A1A`، نسبة الذهبي `#C9A86A`

آخر تقرير: **٤٥ نقطة، صفر مشاكل تخطيط، إضاءة ١٢–٢٧.**
